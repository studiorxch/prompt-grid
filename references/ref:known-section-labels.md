# Known Section Labels and Classification Guidance

This list is guidance for scoring, not a closed vocabulary.

## Strong Structural Labels

- Intro
- Opening
- Entry
- Equilibrium
- System Event
- Procedural Groove
- Drift Chamber
- Behavioral Return
- Reconfiguration
- Forward Motion
- Movement A
- Movement B
- Final Movement
- Bridge
- Interlude
- Breakdown
- Return
- Departure
- Outro

## Common Label Patterns

- `Movement <letter or number>`
- `Final <noun>`
- `<adjective> Return`
- `<noun> Chamber`
- `<noun> Event`

## Usually Instructions, Not Labels

- Forward momentum
- Mechanical precision
- Maximum clarity
- No climax
- No drop
- Drums retreat
- The machinery exhales
- Everything behaves differently
- One kick
- One bass pulse

## Safety Rule

When uncertain, preserve the item as an instruction. Never discard it and never invent a missing section.
