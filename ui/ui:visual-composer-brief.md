# Visual Composer UI Brief

## Visual Direction

- Native Obsidian appearance
- Dense but readable
- Dark-mode first
- No blue or purple accent dependency
- Restrained contrast
- Minimal chrome
- Horizontal section grid
- Fixed toolbar
- Clear character count
- Visible dirty/save state

## Interaction Priorities

1. Reorder sections.
2. Move lines between sections.
3. Edit lines inline.
4. Duplicate and disable lines.
5. Add sections and lines.
6. Save and copy for Suno.
7. Preview validation warnings.

## Avoid

- Oversized cards
- Excessive rounded corners
- Bright gradients
- Floating toolbars that obscure content
- Drag-only controls
- Hidden save state
- Proprietary storage disconnected from Markdown
